# 用 AI 修改 Markdown 简历，用轻简实时预览

[English](ai-workflow.md) · [打开编辑器](../index.html) · [格式说明](../llms.txt)

轻简可以预览外部编辑器或 AI 编码助手修改的简历文件，当前不内置 AI 模型。本指南使用虚构示例和桌面 Chrome 原生目录访问。

## 1. 准备一个文件

下载 [developer-resume.md](../examples/developer-resume.md)，保存到专用文件夹。修改自己的简历前保留备份。示例中的人物、组织和经历均为虚构，不能当作实际项目或候选人成果。

## 2. 连接文件夹

在桌面 Chrome / Edge 中通过 HTTPS 或 localhost 打开轻简，点击“我的简历 → 连接文件夹”，选择专用文件夹并授权读写，再打开列表中的 Markdown 文件。连接和打开文件不会改写它。

## 3. 让外部助手执行明确的修改

```text
先读取轻简当前版本格式说明，再编辑我指定的 Markdown 简历。
只使用我提供的事实，缺失信息用明确占位，不编造经历与数字。
保留现有内容、照片、图标、无关 YAML 字段与排版设置。
只执行我要求的修改，完成后给出文件变更摘要。
由我在轻简复核文字、分页与最终 PDF。
```

把[格式说明](../llms.txt)、准确的文件路径和本次修改要求交给助手。这是文件工作流，当前没有 MCP 接口。外部助手如何处理数据由该工具决定。

## 4. 复核预览

保持编辑器页面活动。前台约每秒检查当前文件；网页没有待保存编辑时，外部修改会更新正文、样式与预览。检查修改后的文字和分页，外部也可修改 YAML 中的排版配置。

尽量避免网页和外部程序同时写入。发生冲突时自动保存暂停，可选“使用磁盘版本”“使用网页版本”或“网页版本另存副本”。对重要文件先看[FAQ](faq.md)和[完整恢复说明](editor-guide.zh-CN.md)，再选择要保留的版本。

## 5. 导出并保留源文件

通过浏览器打印保存 PDF，继续保留 Markdown 源文件作为备份。[打印指南](pdf-export.md)。当前不提供助手自动打印或 ATS 认证。
