# Changelog

## 1.1.0 — Body spacing control

- New `bodySpacing` setting (0–2 multiplier, default 1) scales paragraph, list, and list-item spacing; available in the typography panel and documented in `llms.txt`.
- The compact/comfortable/relaxed typography presets now set line height and body spacing together for a one-click density change; sliders allow independent fine-tuning.

## 1.0.0 — Initial public release

- Markdown editing with live A4 preview, pagination, seven templates, and browser PDF printing.
- Portable YAML + Markdown files, optional photos/icons, and authorized local-folder synchronization with conflict recovery.
- English and Simplified Chinese project introductions, fictional examples, workflow/printing/browser guides, and static public documentation.
- ISC license, contribution guidelines, issue forms, pull-request CI, and documentation/link checks.

The UI is currently Simplified Chinese. AI runs in external tools, not inside the editor; native folder support is limited to capable desktop browsers.
